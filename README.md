# apex-26

A rebuild of [Apex 26 / f1-game](https://github.com/brycejmurrin/f1-game) — the
unofficial browser F1 fan game — on TypeScript + Vite + three.js
(WebGPURenderer with WebGL2 fallback), hosted on GitHub Pages.

Status: planning. Start with [docs/PLAN.md](docs/PLAN.md) and
[ADR-0001](docs/adr/0001-stack.md).
